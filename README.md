# REACTOR BREACH

Reactor Breach is a management game HEAVILY inspired by SCP games, Satisfactory, Factorio, and Prison Architect.

Build and expand a facility, manage energy and escape from the containment breach.

## Current State

The game already has:

- A working reactor in math, but no way to check the values from it right now
- Power and signal systems
- Building
- Inventory
- Mining
- NPCs
- Pause menus
- Online multiplayer (the hardest part)

Many larger features, such as:

- Full SCP behaviours
- Escapes
- Upgrades
- Random disasters
- Economy
- Complete win/lose conditions

are still being developed.
## How to play

I believe the game is pretty self-explanatory but,
- WASD Movement
-B to build and scroll wheel to change build 
-E to interact, pick up minerals around the map and use smelter.
-Smelter is a box near the spawn
-Uranium has no use right now
-You must run away from the npc character chasing you
-left click in power stuff to start creating a power line, right click to go back, doesnt delete.
-Minerals spawn on the spawn plane but dont respawn there and msut go to the other part where the npc character is most active.
