# REACTOR BREACH
Reactor Breach is a management game HEAVILY inspired by SCP games, Satisfactory, Factorio, and Prison Architect.
Build and expand a facility, manage energy and escape from the containment breach. 
Current state: The game already has a working reactor in math, but no way to check the values from it right now, not being usable by anyone still, power and signal systems, building, inventory, mining, NPCs, pause menus, and online multiplayer (the hardest part).
Many larger features, such as full SCP behaviours, escapes, upgrades, random disasters, economy, and complete win/lose conditions, are still being developed.
I have a lot of ideas for this project still, but it is my first game and I believe i already reached my peak, being really diffcult now to debug network, code and others.
